# Веб-приложение "Мой магазин"

Веб-приложение на Flask с использованием Bootstrap для верстки. Реализует страницу каталога товаров, страницу контактов с формой обратной связи, обработку POST-запросов и демонстрацию работы с контекстным менеджером.

## 📋 Содержание

- [Технологии](#технологии)
- [Функциональность](#функциональность)
- [Установка и запуск](#установка-и-запуск)
- [Тестирование](#тестирование)

## 🛠 Технологии

- **Python 3.8+** - язык программирования
- **Flask 2.3.3** - веб-фреймворк
- **Bootstrap 5.3** - CSS-фреймворк для верстки
- **HTML5** - разметка страниц

## 🚀 Функциональность

- ✅ Главная страница с каталогом товаров (3 товара в виде карточек)
- ✅ Страница контактов с формой обратной связи
- ✅ Обработка POST-запросов с выводом данных в консоль
- ✅ Демонстрация явного использования контекстного менеджера `with open()`
- ✅ Кастомные страницы ошибок 404 и 500
- ✅ Адаптивная верстка с использованием Bootstrap
- ✅ Единый дизайн (хедер, боди, футер) на всех страницах

## 📦 Установка и запуск

### 1. Клонируйте репозиторий:

```

git@github.com:HapkoM01/Django---.git

```

### 2. Создание виртуального окружения:

#### Windows:

```
python -m venv venv
venv\Scripts\activate
```

#### Mac/Linux:

```
python3 -m venv venv
source venv/bin/activate

```

### 3. Установка зависимостей

```

pip install -r requirements.txt

```
### 4. Запуск приложения

```
python app.py
```
### 5. Открытие в браузере

```
Перейдите по адресу: http://127.0.0.1:5000
```

## 🧪 Тестирование
### Проверка работы приложения

#### 1. Главная страница

```
Откройте http://127.0.0.1:5000

Проверьте отображение 3 карточек товаров

Убедитесь в наличии хедера и футера
```

#### 2. Страница контактов

```
Перейдите по ссылке "Контакты" или откройте http://127.0.0.1:5000/contacts

Проверьте наличие формы обратной связи
```

#### 3. POST-запрос

```
Заполните форму на странице контактов

Нажмите "Отправить"

Проверьте консоль сервера - должны появиться введенные данные

```

#### Пример вывода в консоли:

```

=====================================
=== Получены данные из POST-запроса ===
Имя: Иван Петров
Email: ivan@example.com
Сообщение: Тестовое сообщение
=====================================
```
#### 4. Контекстный менеджер

```
Откройте http://127.0.0.1:5000/read-contacts

Убедитесь, что страница контактов отображается

Проверьте, что используется with open() в коде
```

#### 5. Ошибка 404

```
Откройте любую несуществующую страницу, например http://127.0.0.1:5000/test

Должна появиться кастомная страница 404
```
